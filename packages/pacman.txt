# Official Arch/CachyOS packages only.
#
# Baseline: a CachyOS installation with the "Niri / Noctalia" desktop profile,
# which installs cachyos-niri-noctalia. This manifest records only what the
# managed configuration, helpers, validation, and documented setup need on top
# of or from within that baseline. Kernel, bootloader, driver, filesystem, and
# other installer-owned packages are deliberately not recorded; see ADR-0009.
#
# One package per line; an inline comment may follow. Compare this manifest
# with the machine using scripts/check-packages.sh.

# Repository checkout, deployment, and validation.
git
chezmoi
fish
shellcheck
shfmt
diffutils

# Desktop session from the CachyOS profile, referenced directly by the config.
cachyos-niri-noctalia
niri

capitaine-cursors # cursor theme in niri misc.kdl

greetd
acl
