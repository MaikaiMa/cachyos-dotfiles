# Architecture decision records

ADRs document durable, system-wide technical decisions before they are
implemented. Name them sequentially as `ADR-NNNN-short-title.md` and keep
superseded records intact; a later ADR should reference the earlier one.

Each ADR includes status, date, context, decision, consequences, and
alternatives considered.
